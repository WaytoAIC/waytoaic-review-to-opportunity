# 验证范围

作者：waytoaic。版本：1.1.0。验证日期：2026-09-16。

## 已验证的范围

- Skill frontmatter、命名、UI 元数据与文档结构检查通过。
- 本地 Python 3 标准库脚本的 18 项回归测试通过，见 tests/test_workbench.py 与 tests/test_html.py。
- 覆盖：变体规范化、去重与图片合并、独立人数留空、冲突 ID/布尔拒绝、缺正文保留、重复运行一致性、产物损坏检测、未知引用与伪造摘录拒绝、部分分析不得声称全量、跨款不得冒认目标款、业务确认必须有记录、决策卡必须提供成功判据。
- 真实数据准备回放：匿名美国站案例 的 389 条去重记录 → 20 批；7 条缺正文、19 条 Vine、136 条有图片；精确目标款记录 0 条。重复执行 hash 一致。
- 前期手工核验已查看 3 张评论图片，区分图片存在、静态观察和不能证明的动态故障。该核验不是自动图像真实性识别能力。

## 独立前向试跑

另一个 Agent 仅获得 Skill 与规范原始评论，不读取父任务分析和预期答案。在不联网的限定条件下生成 1 张问题证据卡及 5 类决策卡，保留 partial 范围、跨变体局限、未知独立人数、未查看图片，并在无外部数据时将定投 ASIN 卡标为 blocked，没有编造 ASIN 或搜索量。

试跑扩展到标题/正文及常见拼写、工具词，共阅读 40 条候选记录，排除 1 条真空包装后 39 条相关。按本次口径分为 30 条困难描述、7 条正面/有条件正面、2 条建议/预测；不是 39 个已核实用户，也不是总体发生率。本次覆盖不同于早期只检索正文 vacuum 的 36 条，不混用计数。

试跑发现成功判据未独立建字段，已补 acceptance 并新增回归检查；试验方案状态改为 test_plan，避免暗示资源已就绪。

## 还不属于已验证的范围

- 市场机会成立、产品实测、利润提升、转化改善、广告效果。
- 评论真实性、独立用户身份和图片真实性的自动判断。
- 本例 389 条全量语义分析；实际聚焦吸尘相关文本。
- 自动关键词/ASIN 获取、全平台通用字段适配及生产自动投放。

check 脚本通过只说明结构与引用检查通过，不说明需求判断或市场结论正确。业务效果须另有执行及结果证据。不得将“已验证 Skill”简写为“五类业务效果都已验证”。

## 复现

```bash
python3 -m unittest discover -s tests -v
python3 scripts/review_workbench.py prepare --input reviews.jsonl --output run --asin ASIN --marketplace US --color '目标颜色' --size '目标尺寸'
python3 scripts/review_workbench.py check --run run --analysis analysis.json
```

真实评论数据由用户在运行目录保存，不随 Skill 分发；本包仅含合成测试数据。跨工具取数前重新读取当时工具 schema。

最终合同复核通过：40/389 条部分分析、1 张问题卡、5 类决策卡；acceptance 与 verification 分开，product_iteration 为 test_plan，asin_targeting 为 blocked。检查结果 structural_check: passed，语义与业务有效性不由脚本认证。

## HTML 输出验证

新增独立离线 HTML 渲染器，先通过结构与引用检查再输出。4 项新增测试覆盖五类动态卡片、文本转义、无效证据拒绝、空分析不编造。真实案例页面已检查页签切换、评论搜索、桌面无横向溢出及无控制台错误。页面展示不等于业务结论验证。
